02

Identity & Access Management · PowerShell · Bash

IAM Lifecycle Automation Lab

IN PROGRESS

Building a simulated identity lifecycle for a fictional organization so access decisions are based on defined rules instead of one-off manual assignments. The lab models Joiner-Mover-Leaver workflows, RBAC, least privilege, access reviews, and audit logging.

PowerShellBashRBACLeast Privilege JMLCSV / JSONAccess Reviews
View project details

Problem

Manual access assignment is inconsistent and makes it easier for users to keep permissions they no longer need. The project asks: based on a user's identity, department, role, and status, what access should they have?

What I’m building

HR-style CSV inputs feed a role-based policy that calculates expected groups, updates lifecycle state, flags excess managed access, and records changes for review. I’m implementing the workflow in PowerShell and Bash so I can compare how the same IAM logic maps across different administration environments.
